# Changelog

All notable changes to Wall-B-Gone will be documented in this file.

The format is based on Keep a Changelog, and this project uses SemVer-style versioning tags.

## [0.1.0-beta.1] - 2026-02-10
### Added
- In-game plugin settings tab for Wall-B-Gone:
  - Enable/disable toggle.
  - Dismantle hotkey rebind/reset controls.
  - Persistence via `mod-config.json` (`enabled`, `hotkey`).

## [0.1.0-alpha.1] - 2026-02-07
### Added
- Initial public release of Wall-B-Gone.
- Wall dismantle hotkey behavior.
- Deployment packaging for RE_Kenshi mod loading.
