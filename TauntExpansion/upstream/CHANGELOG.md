# Changelog

## v1.0 RC1

- Renamed the project and public mod package to **Taunt Expansion**.
- Multiplies Kenshi's confirmed vanilla Taunt score bonus of `+2.0`.
- Added independent `RetargetMultiplier` for evaluations with a valid old target.
- Default configuration set to `Multiplier = 5.0` and `RetargetMultiplier = 2.0`.
- Candidate diagnostic logging disabled by default.
- Retained instruction verification and avoided modifying the shared vanilla constant.
