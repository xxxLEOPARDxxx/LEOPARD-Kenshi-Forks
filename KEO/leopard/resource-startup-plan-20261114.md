# KEO startup texture warmup - private design and implementation plan
Goal: pre-read texture files from the engine's registered FileSystem resource locations, before first visits. Reuse the existing real archive RAM consumer. No world/NPC activation. Keep text-only HUD.
Ruling: texture startup mode is an extra opt-in live flag, default off. Existing RAM/DDS/mesh consumer remains. Geometry retention is a separate follow-up with verified native ownership; no pretend VRAM counters.
Architecture: successful native addResourceLocation calls copy path + recursion; never use engine pointers on IO worker. Existing IO worker enumerates bounded own paths, then reads selected DDS textures using its current rate/memory guards. Normal native observed requests take priority. Startup reads never evict requested resources to scan the whole library forever. Cap/pressure ends or pauses bounded work, show exact counts/bytes and skipped items; do not show a misleading global percentage while inventory expands.
Limits: 8192 roots, 65536 directories, 262144 texture entries, MAX_PATH, no reparse traversal or network drives. Skip uncacheable >256MiB files. Shared RAM cap1..32GiB, current reserve2GiB/20%. Worker cancellation/off/config changes safe. No frame-time waits.
Task1: tests RED for startup inventory/reparse/dedup/cap/priority/stop; implement in store with dedicated API copying root input and stats. Native actual store tests.
Task2: exact-byte admitted addResourceLocation native boundary and initial registered-location snapshot; start early capture before scene, main/menu-safe heartbeat. Defaults/EN RU ZH and meaningful text progress. Test actual ABI/imports and HUD policy.
Task3: native DEV/PROD build, independent lifetime/perf review, source sync exact manifest excluding unrelated jobs dirty files, commit/push. Preserve INI except opt-in startup flag. Install only if game actually closed, otherwise ask close. Snapshot current real session first.
Review focus: reading disabled/unregistered mods, changed roots/late mods, low memory/budget saturation, menu font readiness/reload, in-flight shutdown/path aliases and duplicate files. No release/public changelog.
