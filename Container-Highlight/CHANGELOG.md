# Changelog

All notable changes to Container Highlight will be documented in this file.

## [0.1.0] - 2026-05-01
- Add Mod Hub settings for the highlight key, tint color, marker text, marker icon, and marker color.
- Add a contrasting larger text layer behind marker labels so custom marker text stays readable.
- Add advanced debug logging plus probe and render trace actions.
- Support modifier-only highlight keys.
- Remove the ineffective box-style screen highlight toggle from the exposed options.
