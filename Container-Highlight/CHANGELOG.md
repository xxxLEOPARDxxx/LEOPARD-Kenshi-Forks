# Changelog

All notable changes to Container Highlight will be documented in this file.

## [0.1.0] - 2026-05-01
- Initial release of Container Highlight for marking nearby lootable containers while the highlight key is held.
- Configurable screen-space marker text, marker icon, marker color, and readable outlined labels.
- Optional container tinting with configurable tint color when a container exposes a compatible render path.
- In-game Mod Hub controls for the highlight key, marker display, tinting, distance, and advanced diagnostics.
- Modifier-only highlight key support for Shift, Alt, or Ctrl based activation.
