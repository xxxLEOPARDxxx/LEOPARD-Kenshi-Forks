# LEOPARD Kenshi Forks

Forks of other authors' RE_Kenshi plugins for Kenshi, with LEOPARD's changes:
settings in Mod Config Menu (MCM tab in the game's Options window) instead of
Emkej's Mod Hub, Russian/Chinese translations, fixes and optimisations.

Each folder is one mod with its full history (the original author's commits
plus ours):

| Folder | Original |
|---|---|
| Auto-Pause-on-Load | [Emkej](https://github.com/Emkej/Auto-Pause-on-Load) |
| Container-Highlight | [Emkej](https://github.com/Emkej/Container-Highlight) |
| Hidden-Faction-Relations | [Emkej](https://github.com/Emkej/Hidden-Faction-Relations) |
| Job-B-Gone | [Emkej](https://github.com/Emkej/Job-B-Gone) |
| Loot-Scoot-Execute | [Emkej](https://github.com/Emkej/Loot-Scoot-Execute) |
| Map-markers | [Emkej](https://github.com/Emkej/Map-markers) |
| Organize-the-Crafting-Stations | [Emkej](https://github.com/Emkej/Organize-the-Crafting-Stations) |
| Organize-the-Inventory | [Emkej](https://github.com/Emkej/Organize-the-Inventory) |
| Organize-the-Trader | [Emkej](https://github.com/Emkej/Organize-the-Trader) |
| Vital-Read | [Emkej](https://github.com/Emkej/Vital-Read) |

Our own plugins and the shared headers these forks include (Localization.h,
ModConfigMenu.h, McmModHubBridge.h, WidgetRef.h, HoldKey.h) are in
[LEOPARD-Kenshi-Plugins](https://github.com/xxxLEOPARDxxx/LEOPARD-Kenshi-Plugins) (`shared/`).
